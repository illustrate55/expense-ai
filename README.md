# ExpenseAI

AI-powered personal expense tracker built with Python.

## About

ExpenseAI is a personal finance application designed to help users track expenses, manage budgets, and understand their spending habits with the help of AI.

## Planned Features

- Expense and income tracking
- Transaction categories
- Monthly budgets
- Financial dashboard and statistics
- AI-powered transaction categorization
- AI-generated financial insights

## Tech Stack

- **Language:** Python
- **Backend:** FastAPI
- **Database:** PostgreSQL
- **AI:** GigaChat API
- **Containerization:** Docker
- **Version Control:** Git and GitHub

## Project Status

Currently in development. The initial project structure and development environment are being prepared.
